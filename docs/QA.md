# Проверка XBOOK LAB

## Среда

Проверка выполнена 06.09.2026 в Linux-sandbox на Node.js 22.22.3 / npm 10.9.8. Точные версии зависимостей закреплены в lockfile. Браузер — npm-пакет Chromium 149.0.0 через Playwright 1.63.0; обычная загрузка браузера Playwright из CDN в этой среде не прошла TLS-соединение.

## Подтверждённые результаты

| Проверка                              | Результат                 |
| ------------------------------------- | ------------------------- |
| TypeScript (`npm run typecheck`)      | Успешно                   |
| Vitest (`npm test`)                   | **50 / 50**               |
| Playwright + axe (`npm run test:e2e`) | **23 / 23**, без повторов |

Дополнительно успешно выполнены **production-сборка** (`npm run build`) и **проверка форматирования**. `npm audit --audit-level=high` сообщил **0 известных уязвимостей** на дату проверки.

В production preview отдельно проверены восемь маршрутов, поиск команды `winver`, заполненная таблица сравнения и предупреждение даже при небольшой разнице температуры комнаты. Axe не обнаружил нарушений в проверенном состоянии сравнения. На 320 px проверены обзор, охлаждение, заполненный журнал и источники, включая внутреннюю горизонтальную прокрутку таблицы. Не зафиксировано ошибок страницы, неудачных запросов или обращений приложения к сторонним origin.

### Модульные тесты

- Пустое состояние без фиктивной сборки, температуры и результатов.
- JSON, версия схемы, формы данных, безопасное восстановление и защита исходной записи.
- Удаление дубликатов, допустимые ID, диапазоны, максимум 200 измерений.
- Валидация номера сборки и его соответствия 23H2 / 24H2 / 25H2.
- Неизмеренные значения остаются `null`, не становятся нулями.
- Сравнение FPS и температур; несовпадение игр, сцен, разрешения, питания, охлаждения, длительности, профиля, температуры комнаты и порядка этапов.
- Читаемый отчёт, ссылки, целостность инструкций и маршрутов, список разрешённых команд.

### Браузерные сценарии

- Все восемь маршрутов, неизвестный hash, отсутствие необработанных ошибок страницы.
- «Пока не знаю», редактирование паспорта, несовместимая сборка, сохранение после перезагрузки.
- Чек-лист, копирование команды без запуска, возврат к сохранённой отметке.
- Поиск с клавиатуры, стрелки, `Enter`, `Escape`, пустая выдача, возврат фокуса.
- Выбор игрового профиля, клавиатурный FPS-slider, черновик/сохранение.
- Переключение иллюстративных режимов X6 и восстановление выбора.
- Полный цикл замера: валидация → сохранение → сравнение → изменение → экспорт → перезагрузка → отмена удаления → подтверждение удаления.
- Повреждённый JSON не перезаписывается; исходную запись можно скачать. Сброс подтверждается и не трогает чужой localStorage-ключ.
- При отказе записи в localStorage нет падения и нет ложного сообщения о сохранении на диске.
- Фильтрация и поиск источников.
- Мобильная навигация всех страниц и ширина формы при viewport 360 px.

### Доступность и визуальная проверка

Axe проверяет теги `wcag2a`, `wcag2aa`, `wcag21aa`, `wcag22aa`: все восемь страниц, дополнительные вкладки Windows, раскрытые аккордеоны, паспорт, форму, поиск, инструкцию и мобильное меню. В протестированных состояниях **нарушений axe не обнаружено**. Это не сертификат полной доступности.

Проверены клавиатурное удержание и возврат фокуса в нативных диалогах. Настройка `prefers-reduced-motion` учитывается и в Motion, и в CSS; декоративные вентиляторы не вращаются постоянно.

Снимки сохраняются в `.cache/screenshots/`: desktop 1440 px и дополнительные варианты 390 / 768 / 1024 / 1280 px. Выполнен визуальный просмотр композиции, типографики, иллюстрации, ключевых страниц и мобильной формы. PNG — артефакты проверки, не production-ресурсы и не содержимое Git.

## Исправления по результатам проверки

- Исправлены JSX таблицы Windows и отсутствующий импорт `useId`.
- Усилена контрастность вторичного текста и ссылок; у мобильной кнопки поиска есть доступное имя.
- Начальный фокус задаётся **после** `showModal()`, а не до открытия нативного диалога.
- Ошибка формы получает фокус и прокрутку в видимую область.
- Устранена минимальная ширина CSS-grid, вызывавшая переполнение X6 на 360 px. Контейнер таблицы удерживает скрытые подписи внутри своей области прокрутки, не расширяя страницу на 320 px.
- Ссылка на параметры CPU отделена от ссылки на загрузку AMD-драйверов.
- Частично повреждённое состояние и ошибочные сборки не дают молча перезаписать исходную запись.
- При недоступном сохранении интерфейс явно различает память сеанса и localStorage.
- HTML из Playwright-артефактов исключён из наблюдения Vite: иначе тестовые файлы инициировали перезагрузки сайта.

## Границы проверки

- Ноутбук, Windows, драйверы и охлаждение физически **не тестировались**. Никакие FPS, температура, шум или результат отката не объявляются измеренными.
- Нет отдельного прогона Firefox/WebKit, NVDA/VoiceOver и физических телефонов. Эмуляция viewport не равна такому прогону.
- Автоматические проверки не доказывают безопасность произвольного твика, совместимость BIOS или отсутствие всех возможных ошибок UI.
- В bundled Chromium наблюдалась нестабильность при записи трассировки на каждом шаге длинных сценариев с перезагрузкой. Обычный полный прогон прошёл без трассировки каждого шага; конфигурация использует `on-first-retry`. Браузерный fallback не является production-зависимостью.
- Ошибки внешних сайтов, блокировки доступа и последующие изменения их содержимого не контролируются приложением. У справочника фиксированная дата редакции.

## Повторение

```sh
npm ci
npm run typecheck
npm test
npm run test:e2e
npm run format:check
npm run build
```

При наличии стандартного установленного Chromium конфигурация использует его. На Linux при отсутствии скачанного браузера задействуется воспроизводимый npm-fallback из `tests/browser.ts`. Внешние ссылки в E2E не обходятся и не выполняют настройку Windows.
